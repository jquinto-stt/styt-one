# ST&T One · Demostración local

Esta demostración local permite recorrer el flujo principal de **ST&T One** desde el navegador con cuentas y datos ficticios, sin conexión a sistemas productivos.

## Cuentas ficticias

Selecciona una cuenta en la pantalla de acceso. Las tres usan la contraseña de demostración `Demo-One-2026`.

| Cuenta | Identidad | Acceso |
|---|---|---|
| colaborador | Ana Torres | Perfil propio, políticas generales y Atlas |
| lider | Luis Vega | Perfil propio, políticas generales, Atlas y Faro |
| admin | Sara Mora | Perfil propio, políticas generales, Atlas y Faro, edición de políticas y fichas |

## Recorrido de presentación

1. Entra como Ana. Escribe «¿Cómo pido vacaciones?» y abre la referencia. Se abre la sección exacta en otra pestaña. Vuelve al chat y prueba «¿Qué pasos sigo para solicitar vacaciones?».
2. Consulta tu perfil y tus proyectos. Selecciona Atlas para ver su resumen y su ficha. Pregunta por viáticos para ver el aviso de política vencida, o por una política de mascotas para ver la respuesta sin evidencia.
3. Intenta acceder al proyecto Faro como Ana para comprobar la denegación. Cierra sesión y entra como Luis. Pulsa «Estado de proyecto», elige Faro y comprueba cómo aparece una fecha sin documentar.
4. Entra como Sara y abre Administración. Publica una revisión de vacaciones o edita la ficha de Atlas. Repite la consulta y vuelve a abrir la demostración para comprobar la persistencia. Las modificaciones pasan a formar parte de tu demo local.

## Funcionamiento

La demostración conserva localmente las cuentas, membresías, sesiones, versiones de documentos y fichas de proyectos. Las sesiones vencen tras ocho horas y se invalidan al cerrar sesión. Las políticas son generales para todas las cuentas autenticadas, mientras que cada ficha es el documento fuente del proyecto y requiere membresía. Los mensajes del chat solo permanecen activos durante la sesión de la pestaña.

El asistente reconoce consultas frecuentes en español y presenta únicamente contenido de registros autorizados. Todas las políticas y personas de muestra son ficticias.
